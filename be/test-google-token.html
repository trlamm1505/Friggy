🔑 Friggy — Google ID Token Generator

Dùng để lấy idToken test endpoint POST /api/v1/auth/google

✅ ID Token lấy được — copy vào Postman:

Paste vào Postman → Body → { "idToken": "..." }

Cách dùng:
1. Thay YOUR_GOOGLE_CLIENT_ID bằng Client ID thật trong file này
2. Mở file bằng browser (Live Server hoặc mở thẳng file://)
3. Đăng nhập Google → copy token → paste vào Postman

Postman:
POST http://localhost:6969/api/v1/auth/google
Body: { "idToken": "<token vừa copy>" }
